# Corey Haines · marketingskills (MIT, 50 Skills, chaque Skill a evals/evals.json), parties utiles à LinkedIn

1. **Contexte produit** (product-marketing) : fichier de contexte unique lu par tous les Skills (`.agents/product-marketing.md`), 12 sections : produit, audience, personas, douleurs, concurrence, différenciation, objections et anti-personas, dynamique de changement, **LANGAGE CLIENT VERBATIM** (comment ils décrivent le problème / la solution, mots à utiliser / éviter, glossaire), voix, preuves, objectifs + changelog. → notre contexte entreprise doit contenir le vocabulaire client verbatim et les objections.
2. **Social** : questions de cadrage (objectif, audience, voix, RESSOURCES : temps, contenu à recycler, vidéo possible ?) ; piliers en % ; plateformes (LinkedIn 3-5/sem, 1 200-1 500 car. selon lui, encore un autre chiffre → à arbitrer).
3. **5 frameworks de carrousel** (choisir selon la nature du contenu) : A Value-Stack (nombre exact promis = promesse vérifiable, pas de remplissage), B Problem-Proof (résultat chiffré → vrai problème → mécanisme nommé → détail littéral à sauvegarder → PREUVE en dernière slide : boucle ouverte/fermée), C Hack List (techniques NOMMÉES, chaque slide survit seule), D Rant Callout (avec le PIVOT d'équité « je ne vise pas X »), E Demo Walkthrough (résultat d'abord, VUE D'ENSEMBLE des étapes avant le détail, vraies captures recadrées). Règles : slide 1 = vignette autonome ; UN gabarit visuel ; police ≥28 pt à 1080 px ; 1 seul CTA ; texte du post = sa propre accroche ; mesurer sauvegardes et complétion, pas les likes.
4. **Écoute / commentaires** : grille de priorité des posts à commenter (adéquation ICP ×2, signal d'intention ×2, potentiel de portée ×1, opportunité de commentaire utile ×2, fraîcheur ×1) ; règles d'exclusion (>24 h et >50 commentaires, slop, rien à ajouter) ; 3 niveaux de commentaire (relation : 2-4 phrases avec vécu chiffré ; visibilité : 1-2 phrases ; entretien : 1 phrase qui cite une ligne). Mode navigateur sur LinkedIn → À ÉCARTER (scraping interdit par les CGU).
5. **Rétro-ingénierie de contenu** en 6 étapes (créateurs du créneau → collecte → analyse quanti/quali du top 10% → playbook → voix → conversion). Collecte via Apify/PhantomBuster → À ÉCARTER (CGU LinkedIn) ; garder la collecte manuelle (copier-coller, swipe file).
6. **Relecture en 7 passes** (clarté, voix et ton, « et alors ? », prouve-le, spécificité, émotion, zéro risque : objections près du CTA, prochaine étape claire) + alternatives en langage simple.
7. **Prospection / conformité** : RGPD (intérêt légitime : rôle pro, source publique pro, opt-out clair, test écrit ; noter source + date + base légale de chaque contact ; droits d'accès/suppression ; info de confidentialité dès le 1er contact ; minimiser la conservation) ; scraping LinkedIn = violation CGU + risque RGPD ; adresses perso = risque. Affirmation « messages LinkedIn hors RGPD » → à vérifier pour la France (CNIL : prospection B2B, information art. 14 RGPD si on stocke les données dans un CRM).
8. **Cold email** : relances avec décalage de jours, personnalisation, objets (utile pour les messages privés).
9. Chaque Skill : evals/evals.json (prompts réalistes + attentes).
