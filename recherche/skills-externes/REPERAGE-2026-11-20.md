# Skills externes pour les catégories vides : rapport de repérage

Date : 20 novembre 2026. Recherche seule : aucun fichier du dépôt Join Médicis modifié, rien publié.

## Méthode et limites

- 24 dépôts clonés (`git clone --depth 1`) dans ce dossier, licences lues dans le clone. Aucun script téléchargé n'a été exécuté (consigne) : les scripts sont décrits d'après leur code (imports, fonctions), pas d'après une exécution.
- Étoiles : l'API GitHub est bloquée dans cette session. Les chiffres viennent de la page GitHub de chaque dépôt, relevés le 20/11/2026 par lecture automatique : à recouper avant affichage sur le site.
- Date du dernier commit : `git log -1` dans le clone.
- Lecture : chaque SKILL.md recommandé est lu en entier, avec ses références principales. Pour les gros dépôts (alirezarezvani : 3 962 fichiers ; mohitagw15856 : 8 725 ; the-utopia-studio : 4 244), seuls les Skills pertinents ont été lus. La liste exacte est en fin de rapport. C'est un repérage, pas la rétro-ingénierie complète exigée par le CLAUDE.md avant d'écrire nos propres Skills.

### Faits France vérifiés à la source

- **CNIL, prospection par courrier électronique** (page mise à jour le 10 juin 2026, consultée le 20/11/2026, cnil.fr/fr/la-prospection-commerciale-par-courrier-electronique) :
  - B2C : consentement préalable, « libre, spécifique, éclairé et univoque », case pré-cochée interdite. Exception : client existant et produits ou services analogues de la même entreprise ; la création d'un compte sans achat ne suffit pas.
  - B2B : intérêt légitime possible si l'objet est en rapport avec la profession du destinataire ; la personne doit être informée et pouvoir s'opposer.
  - Adresses génériques (contact@, info@) : non soumises à ces principes.
  - Chaque message identifie l'émetteur et permet de refuser simplement ; droits traités sous un mois.
  - La page n'exige pas le double opt-in.
- **Loi n° 2023-451 du 9 juin 2023 (influence commerciale)** : l'article 5 impose la mention « publicité » ou « collaboration commerciale », claire, lisible et identifiable. Source : Direction des affaires juridiques de Bercy, citée par un résultat de recherche ; Légifrance et economie.gouv.fr ont répondu 403 à la lecture automatique. **[à vérifier au texte consolidé]**. Le contrat écrit et ses mentions, ainsi que le décret n° 2026-233 du 30 mars 2026 cité par un article, sont **[à vérifier]**.

### 1.1 Brevo Skills (officiel Brevo) : le plus adapté au marché français

- **Dépôt** : getbrevo/brevo-skills, `skills/email-template-write`, `email-template-check`, `email-campaign-create`, `automation-create`, `email` (routeur) et 5 autres.
- **Commit** : 88db934. **Licence** : MIT (© 2026 Brevo). **Étoiles** : 2 (relevé surprenant pour un dépôt officiel, à recouper). **Dernier commit** : 17/11/2026.
- **Ce qu'il fait** :
  - `email-template-write` (296 lignes, 9 références) : brief en 5 questions au plus, une à la fois (URL, objectif, audience, accroche, offre). Il écrit ensuite un HTML compatible messageries avec le langage de modèles Brevo (`{{ contact.FIRSTNAME }}`, conditions, boucles).
  - Règles de rédaction chiffrées : objet de 40 à 50 caractères, prévisualisation d'environ 100 caractères, paragraphes de 2 ou 3 phrases, pas de tirets longs.
  - `email-template-check` : contrôle à liste fixe (syntaxe, attributs existants, images https, taille, lien de désinscription), 3 tours de correction au plus.
  - `automation-create` : workflow créé en brouillon après validation, jamais activé sans un « oui » explicite.
  - Garde-fous forts sur tous les Skills : jamais de clé API dans la conversation, aucun envoi réel sans accord, aucun identifiant inventé.
- **Portabilité : Partout** pour la rédaction, l'envoi et l'enregistrement demandant le connecteur MCP Brevo (OAuth).
  - Standard Agent Skills respecté (SKILL.md, `references/`), sans `allowed-tools`.
  - Manifestes fournis pour Claude, Codex, Cursor, Gemini CLI et Grok ; `docs/platforms.md` documente le ZIP pour claude.ai, ChatGPT et l'app Gemini (« vérifié en octobre 2026 » selon eux).
  - `email-template-write` fonctionne sans connexion (« offline mode »).
  - À retirer pour le web : `brevo-cli` (terminal requis) et les fichiers `agents/openai.yaml` (métadonnées Codex).
  - Mistral : non documenté.
- **Points faibles, risques France** :
  - Pied de page et lien de désinscription en anglais (« Unsubscribe ») : à traduire.
  - Lisibilité calée sur « US 8th grade ».
  - Aucune vérification de consentement ni de base légale : les Skills ne vérifient que la présence du lien de désinscription. À compléter avec les règles CNIL ci-dessus.
  - Statut « beta » sur chaque Skill.
  - Utile seulement aux clients Brevo (offre gratuite **[à vérifier]**).
- **Verdict** : **à ajouter avec avertissement** (Brevo requis pour agir ; règles CNIL à ajouter dans la fiche).
