# Join Médicis · Ressources

Les ressources open-source de [Join Médicis](https://joinmedicis.com), la
bibliothèque IA gratuite pour les marketeurs francophones : des Skills Claude
(compatibles ChatGPT, Gemini et Mistral) écrits en français, pour le marché
français.

## Packs

| Pack | Contenu | Fiche |
|---|---|---|
| [LinkedIn Skills](linkedin-skills/) | 12 Skills : posts, commentaires, réponses, profil, plan, carrousels, recyclage, messages privés, messagerie, audit, recherche d'offres et un humaniseur français | [joinmedicis.com](https://joinmedicis.com/ressources/skills/linkedin-skills) |

## Installer un pack dans Claude Code

```
/plugin marketplace add Aleksander-Siebert/join-medicis-ressources
/plugin install linkedin-skills@join-medicis
```

Pour claude.ai, ChatGPT, Gemini et Mistral, voir le README de chaque pack.
