# Le bon type de page

Une page très bien rédigée ne se classe pas si elle n'est pas du type que
Google montre pour la requête. On le vérifie **avant** de planifier.
Méthode adaptée de seo-sxo (claude-seo, MIT ; auteur d'origine Florian
Schmitz) et de keyword-deep-dive (superseo-skills, Apache 2.0), réécrite.

## Les types

| Type | Signes dans la SERP et sur la page |
|---|---|
| Guide, article | auteur, date, plan en H2, extrait optimisé, « Autres questions posées » nombreuses |
| Liste, « meilleurs X » | titres avec un nombre, tableaux récapitulatifs |
| Comparatif « X ou Y », « alternatives à » | « vs », « ou », « comparatif » dans les titles, tableaux de critères |
| Page produit ou d'offre | prix, garanties, bouton de devis ou d'achat, avis |
| Page catégorie | liste de produits ou d'offres, filtres |
| Outil, simulateur | calculateur, formulaire, résultat immédiat |
| Page locale | pack local (carte), adresse, horaires |
| Actualité | dates récentes, sites de presse, carrousel « À la une » |
| Définition | « X est… » en première phrase, encadré de définition |

## Le consensus

Classe les 10 premiers résultats organiques (hors annonces) :

- **plus de 60%** du même type : consensus fort, on suit ce type ;
- **40 à 60%** : consensus moyen, on suit le type majoritaire et on reprend
  ce que la minorité apporte ;
- **moins de 40%** : SERP fragmentée, c'est une ouverture ; le format le
  plus utile au lecteur peut gagner.

Écris-le : « Guides 7/10, comparatifs 2/10, page d'offre 1/10 : consensus
fort pour un guide. »

## Quand la page prévue n'est pas du bon type

| Prévu | La SERP montre | Gravité | Que faire |
|---|---|---|---|
| article | pages produit ou d'offre | critique | créer ou renforcer la page d'offre ; l'article la soutient |
| article | comparatifs | haute | prévoir un comparatif avec tableau |
| page produit | guides | haute | ajouter un vrai contenu explicatif, ou un guide séparé qui y mène |
| page de conversion | outils, simulateurs | haute | prévoir l'outil (calculateur, simulateur) |
| page service | pack local | moyenne | signaux locaux, fiche d'établissement (`/seo-local`) |
| même type | | aligné | travailler la profondeur, la clarté et le gain d'information |

Dis-le à l'utilisateur avant de planifier : c'est lui qui tranche.

## Les signaux « ne pas tenter » (ou viser une variante)

Certaines SERP ne se gagnent pas avec un article, quelle que soit sa
qualité. Si l'un de ces signaux est là, propose une variante de longue
traîne ou un autre type de page :

- un site public ou une autorité occupe le haut sur une question
  réglementaire (service-public.fr, ameli.fr, impots.gouv.fr, legifrance,
  sites des ordres professionnels) ;
- Wikipédia tient le top 3 sur une question de culture générale ;
- des forums dominent (le lecteur veut des avis de pairs) ;
- une actualité chaude : les sites de presse tiennent la SERP pour quelques
  jours ;
- des pages produit de grandes marques sur une requête générique : Google
  y voit une intention d'achat.

## La difficulté sans outil payant

Les scores de difficulté des outils divergent fortement d'un outil à l'autre
(superseo-skills cite des écarts de plus de 30 points). En mode gratuit, on
lit la SERP. Compte les signaux présents :

1. Wikipédia, un site public ou un ordre professionnel dans le top 10.
2. Plus de 5 grands sites (presse nationale, grandes marques) dans le top 10.
3. Les 5 premiers résultats sont tous longs et très structurés.
4. L'extrait optimisé est tenu par une grande marque.
5. Un AI Overview est affiché.
6. Les 5 premiers ont tous un auteur identifié avec une expertise visible.
7. Le top 3 contient des données originales ou une méthode propre.
8. Les pages du top 10 sont visiblement entretenues (dates récentes).
9. Un site spécialisé du sujet est dans le top 3.
10. Les titles et descriptions du top 5 sont soignés.

0 à 3 : abordable avec une page seule · 4 à 6 : un cluster et un vrai gain
d'information · 7 à 10 : difficile, il faut de l'autorité et des données
propres. **C'est une lecture directionnelle, pas une mesure** : dis-le, et
ne donne aucun délai de classement.
