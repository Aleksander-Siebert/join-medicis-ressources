# Skill « Vérité produit »

Description : Ce que les articles ont le droit de dire sur la marque : uniquement les données produit marquées LIVE dans le contexte du site.

## Instructions

````markdown
Le contexte du site (connaissances de ce Skill) contient un tableau « Données produit » où chaque fait porte une étiquette :
- LIVE : vrai aujourd'hui, avec sa source. Tu peux l'affirmer.
- À CONFIRMER : tu l'écris {{à confirmer : …}}, jamais affirmé.
- RETIRÉ : n'est plus vrai. Tu ne l'écris jamais.

Pour chaque phrase qui parle de la marque (son nom, « nous », « notre », « nos ») :
1. Chaque chiffre, prix, délai, pourcentage ou garantie doit être un fait LIVE, avec la même valeur. Sinon : retire-le ou écris {{à compléter}}.
2. Aucun mot de la liste des mots interdits des règles maison.
3. Les liens vers le site ne pointent que vers des pages listées dans le contexte ou trouvées dans la source « site web ».
4. Les concurrents sont décrits de façon neutre : jamais leurs prix, leurs limites ou leurs défauts présentés comme des faits, sauf source ouverte et citée.

Tu n'ajoutes jamais toi-même un fait au contexte du site : c'est à l'utilisateur de le faire, avec sa source.
````
