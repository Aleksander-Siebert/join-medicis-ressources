# Les 4 frameworks de structure

Un framework, une intention : on ne mélange pas deux structures sur une même
page. Inspiré de la carte des frameworks d'Empirik (SEO Edition), réécrit.

## Choisir

```
L'objectif principal est la conversion ?
├─ oui → PAS
└─ non
   ├─ c'est une actualité ou une annonce ? → pyramide inversée
   └─ non
      ├─ la page doit aussi convertir (comparatif, avis) ? → AIDA
      └─ non → MECE (guide complet, page pilier)
```

| Framework | Pages | Objectif |
|---|---|---|
| PAS | page produit, landing page, page catégorie orientée achat | conversion |
| AIDA | comparatif, avis, « meilleurs X », page de campagne | information + conversion |
| MECE | guide complet, page pilier, sujet très concurrentiel, cible AI Overviews | autorité SEO et GEO |
| Pyramide inversée | actualité, annonce, réponse directe à une question | lisibilité, position zéro |

## PAS : Problème, Agiter, Solution

- **Problème** : la douleur exacte, dès la première phrase, avec les mots de
  la requête.
- **Agiter** : les conséquences (temps, argent, risque), crédibles. Pas de
  dramatisation : elle détruit la confiance, surtout en YMYL.
- **Solution** : le produit nommé, le bénéfice principal (pas la liste des
  fonctions), une preuve, un seul appel à l'action.

Vérifier : problème dit avec les mots du lecteur · agitation crédible ·
solution nommée avec son bénéfice · un CTA unique.

## AIDA : Attention, Intérêt, Désir, Action

- **Attention** : un fait, un chiffre sourcé ou une affirmation forte liée au
  sujet. Jamais « Dans cet article, nous allons voir ».
- **Intérêt** : les bénéfices pour le lecteur, les mots-clés secondaires.
- **Désir** : preuves vérifiables (avis, résultats, cas), comparaison avec
  l'alternative, sans dénigrer nommément.
- **Action** : verbe + bénéfice immédiat, friction réduite.

Vérifier : accroche factuelle · bénéfices distincts des fonctions · au moins
une preuve vérifiable · CTA sans friction. Sur un format court, préférer PAS.

## MECE : sans recouvrement, sans manque

- **Sans recouvrement** : chaque H2 a son périmètre. Test : si je supprime
  cette section, une autre l'absorbe-t-elle ? Si oui, c'est un doublon.
- **Sans manque** : chaque requête du champ sémantique (20 à 30 requêtes :
  questions de la SERP, Search Console, outil de mots-clés) est rattachée à
  une section. Une requête orpheline = une section à créer.
- Chaque H2 commence par une réponse directe en 1 à 2 phrases : c'est ce que
  les moteurs génératifs extraient.

Vérifier : test de non-recouvrement fait · toutes les requêtes couvertes ·
aucune section de 2 lignes · réponse directe en tête de section. Pas adapté
aux formats courts (moins de 800 mots).

## Pyramide inversée

- **L'essentiel** : qui, quoi, quand, où, dans les 2 premières phrases, avec
  le mot-clé.
- **Le contexte** : pourquoi, origine, implications, sources.
- **Les détails** : fiche technique, liens, citations, pour les plus
  impliqués.

Vérifier : l'info principale tient dans les 2 premières phrases · contexte
sourcé · détails optionnels. Ne pas « construire vers » l'information.
