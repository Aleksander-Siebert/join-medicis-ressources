# entreprise.md

Ce que toute IA doit savoir de ton entreprise avant d'écrire une ligne pour
toi. Copie ce fichier dans `~/.claude/fondation/entreprise.md` (Claude Code)
ou dans les connaissances de ton Projet (claude.ai, ChatGPT, Gemini,
Mistral). Le plus simple : lance `/fondation-entreprise`, qui lit ton site,
te pose les questions une à une et remplit ce fichier avec toi.

> **Ne le mets pas dans un dépôt public.** Il contient tes offres, tes prix,
> tes objectifs et ce qui coince.

## Comment lire les étiquettes

| Étiquette | Sens | Ce que font les Skills |
|---|---|---|
| **LIVE** | vrai aujourd'hui, vérifiable | l'utilisent |
| **À CONFIRMER** | déduit, ancien, incertain | l'écrivent `{{à confirmer : …}}` |
| **RETIRÉ** | n'est plus vrai ou n'est plus dit | ne l'utilisent jamais |

Chaque fait porte une étiquette, une date (« au … ») et une source.

## 5. La différence

Méthode : des alternatives aux attributs, des attributs à la valeur, de la
valeur aux clients qui s'en soucient le plus (April Dunford). Chaque attribut
a une preuve, sinon il reste `À CONFIRMER`.

| Attribut que les alternatives n'ont pas | Preuve | Valeur pour le client | Étiquette | Au | Source |
|---|---|---|---|---|---|
| | | | | | |

**Pour qui cette valeur compte le plus :**

**Phrase de positionnement** (publique, sans superlatif invérifiable) :

> Pour [qui], qui [besoin], [nom] est [catégorie] qui [valeur principale].
> Contrairement à [alternative principale], [différence prouvée].

Test : un concurrent pourrait-il signer cette phrase ? Si oui, elle est à
refaire.
